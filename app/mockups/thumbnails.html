Find thumbnails for all bookmarks?

Each bookmark's link goes to the services it needs: FxTwitter, YouTube, GitHub, wsrv.nl, Microlink, Raindrop and Google. Stored thumbnails are never replaced.

What this shows

  • Nothing is sent until you confirm. The warning lists only the services this bookmark could reach, in the order they're tried. The run stops at the first image found.
  • The counter shows Microlink lookups left today, out of 25. It goes down only when the run reaches Microlink.
  • Once a thumbnail is stored, the button becomes Retry thumbnail. That's the only way it changes.
  • The imported cover stays in the bookmark untouched. The same thumbnail shows in the queue and on the graph node.
  • The setting is off by default. The button works whether the setting is on or off.
  • Copy, Edit and Pin sit in a fixed bar above the title, so a long title no longer moves them. That change is tracked separately in #13, not in #7.
