Notes

  • Each shape is one flat fill with the hole cut through, so the graph background shows through it. No outline, gradient or shadow.
  • Size still sets the tag's height, as it sets the circle's width now. The tag shapes are about 1.6 times wider than tall, so labels sit below as they do today.
  • The circle, rounded square and diamond stay available, so existing types keep working until you change them. Points only applies to the four tag styles.
  • The same Style, Points and Color controls appear in the tag type editor and in a single tag's Appearance override.
  • The presets are dark enough for a white icon to read on them. Custom opens the system color picker. A type whose color isn't a preset shows it on the Custom swatch.
