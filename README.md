# Bubble & Tag

An import-first, local-first workspace for collecting bubbles, organizing them with tags, and processing them through a G6 force-directed graph.

- [Approved product plan](docs/product-plan.md)
- [Checkpoint review guide](docs/product-review-guide.md)
- [Implementation progress](docs/product-progress.md)
- [App setup and current limitations](app/README.md)

```sh
cd app
npm ci
npm run dev
```

Open http://127.0.0.1:5199/. The current milestone is checkpoint A: an import and graph design preview. The UI does not persist imports yet.

The personal bookmark prototype has been reverted on this branch and remains recoverable from Git history.
