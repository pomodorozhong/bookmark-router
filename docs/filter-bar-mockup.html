Compact filter bar

Today's bar holds the search box, three type toggles, the ☰ menu, chips, + Filter and Views on one line, so it wraps as soon as you add a chip. Pick a situation and a width, then compare the three options. Everything is clickable: the menus open, chips can be removed, and types can be hidden. At phone width every option wraps; phone layout is a separate fix.

Recommended

Same compact controls as A. Chips sit in a second row under the bar, which appears only while a filter is on, with a Clear link. The bar itself never changes width, so it never wraps.

C · Chips fold into a count

Same compact controls. + Filter turns into Filters · 2, and the chips live in its menu. The narrowest option, but you have to open the menu to see what is filtered.

Why B: you mostly filter to work through one issue or a gap (Pricing to do, missing descriptions), so seeing the chips at all times matters more than saving a row. A still wraps with the two Pricing chips when the queue is open. C saves the most space but hides what is filtered.
